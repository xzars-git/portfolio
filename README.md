# Arsenius Purbandono: portfolio

Static site (HTML/CSS/JS, no build step) in English, Indonesian and Japanese. Deployed on Vercel.

- Text lives in `i18n.js` (`I18N`, `APPS`, `MODELS`, `SANDBOX`).
- `?lang=en|id|ja` picks the language.
- PDFs in `pdf/` are generated from the print stylesheet: `bash build-pdf.sh` (needs Python and Chrome). Run it again after editing text.

Work from Bapenda Jabar is described with the agency's permission. No source code or internal data from those projects is included.
